WhatsApp অর্ডার তৈরি করুন

প্যাকেজ বেছে নিন, আপনার UID ও payment details দিন। এরপর WhatsApp-এ message খুলবে—আপনি দেখে Send করবেন।

UID-তে শুধু সংখ্যা দেওয়া যাবে—কোনো letter, space বা symbol নয়। UID ৫ থেকে ২০ ডিজিট হতে হবে।
কোনটা দেবেন? Transaction ID হলো bKash payment-এর SMS-এ থাকা আলাদা TrxID। Sender number হলো যে bKash মোবাইল নম্বর থেকে টাকা পাঠিয়েছেন। দুটোই থাকলে দুটোই দিন; TrxID না থাকলে sender number দিন। অন্তত একটি দিতে হবে।

UID সতর্কতা: ভুল UID দিলে এবং likes process/send হয়ে গেলে সংশোধন বা refund নিশ্চিত করা যাবে না। তাই submit করার আগে UID ভালোভাবে মিলিয়ে নিন।

অর্ডার, পেমেন্ট এবং সার্ভিস সম্পর্কে দরকারি তথ্য।

কীভাবে package অর্ডার করব?

কীভাবে পেমেন্ট করব?

UID কোথায় পাঠাব?

WhatsApp order message-এ আপনার Free Fire UID দিন। Password বা OTP কখনো শেয়ার করবেন না।

অর্ডার কখন confirm হবে?

পেমেন্ট ও অর্ডারের তথ্য আমরা হাতে যাচাই করে WhatsApp-এ confirmation দিলে অর্ডার confirm হবে।

Likes কি guaranteed?

Package-এ দেখানো সংখ্যা advertised target/estimate। Actual result service availability বা game-side changes-এর কারণে আলাদা হতে পারে।

Permanent বলতে কী বোঝায়?

50+ Likes Permanent Package-এর দাম ৳1,050 এবং daily target 50+ Likes। Permanent মেয়াদ ও সার্ভিসের শর্ত supplier-এর লিখিত terms-এর ওপর নির্ভর করে; কেনার আগে admin-এর সঙ্গে শর্ত নিশ্চিত করুন।

অর্ডার করার পর কী হবে?

আপনার WhatsApp message পাওয়ার পর admin order details ও payment manually check করবেন। Verification হলে order status জানানো হবে।

ভুল UID দিলে কী হবে?

Send করার আগে UID নিজে ভালোভাবে check করুন। ভুল UID-তে likes process/send হয়ে গেলে আমরা দায় নিতে বা correction/refund দিতে পারব—এমন নিশ্চয়তা নেই। তাই ভুল UID-এর দায় customer-এর; submit করার আগে double-check করুন।

কত সময়ে likes পাব?

Delivery timing package ও service availability অনুযায়ী ভিন্ন হতে পারে। নির্দিষ্ট সময়ের নিশ্চয়তা পাওয়ার জন্য order-এর আগে admin-এর সঙ্গে confirm করুন।

Transaction ID (TrxID) আর Sender number-এর পার্থক্য কী?

Transaction ID (TrxID): bKash payment করার পর SMS-এ পাওয়া লেনদেনের আলাদা ID—এটি আপনার মোবাইল নম্বর নয়। Sender number: যে bKash নম্বর থেকে টাকা Send Money করেছেন। Form-এ TrxID অথবা Sender number—অন্তত একটি দিতে হবে; দুটো থাকলে দুটোই দিন। শুধু Sender number দিলে payment যাচাই করতে একটু বেশি সময় লাগতে পারে।

UID-তে letter দেওয়া যাবে?

না। Free Fire UID-তে শুধু সংখ্যা দিতে হবে, কোনো letter, space বা symbol নয়। UID ৫–২০ ডিজিটের হতে হবে। Submit করার আগে UID ভালোভাবে মিলিয়ে নিন।

Nagad দিয়ে payment করা যাবে?

Nagad number এখনো যোগ করা হয়নি। Admin officially confirm না করা পর্যন্ত Nagad-এ payment করবেন না।

আমার password বা OTP লাগবে?

না। FF ServicesPicks আপনার game password, social account password, bKash/Nagad PIN বা OTP চাইবে না। এগুলো কখনো share করবেন না।

সমস্যা হলে admin-এর সঙ্গে কীভাবে কথা বলব?

নিচের “Chat with admin” button চাপুন। আপনার package বা order সম্পর্কে ছোট message তৈরি হবে; WhatsApp-এ দেখে Send করুন।
