# FF ServicesPicks — README

## bKash নম্বর কোথায় পরিবর্তন করবেন

বর্তমান bKash নম্বর: `01733054857`

HTML ফাইলটিতে এই নম্বরটি **মোট ৩ জায়গায়** আছে:

| লাইন | কোথায় আছে | কী পরিবর্তন করবেন |
|---:|---|---|
| **62** | Payment section-এর `id="bkash-number"` অংশে | এখানে দেখানো bKash নম্বর বদলান |
| **66** | FAQ: “কীভাবে পেমেন্ট করব?” উত্তরে | FAQ-এর মধ্যে থাকা নম্বরটিও বদলান |
| **88** | JavaScript-এর `SETTINGS` object-এ `bkashNumber` | এই মানটি বদলালে পেমেন্ট অংশে দেখানো নম্বর ও Copy button-এর নম্বর আপডেট হবে |

### নম্বর পরিবর্তনের উদাহরণ

ধরা যাক নতুন নম্বর `01XXXXXXXXX`। HTML ফাইলে উপরের ৩টি লাইনে পুরোনো `01733054857` নম্বরের জায়গায় নতুন নম্বর বসান।

**গুরুত্বপূর্ণ:** লাইন নম্বর ফাইল সম্পাদনা করলে বদলে যেতে পারে। তাই শুধু লাইন নম্বরের ওপর নির্ভর না করে `01733054857` লিখে ফাইলের মধ্যে Search করুন। সব ৩টি occurrence আপডেট হয়েছে কি না যাচাই করুন।

## ফাইল কীভাবে সম্পাদনা করবেন

1. `ff_servicespicks_mobile_desktop_preview_v2.html` ফাইলটি VS Code বা অন্য text editor-এ খুলুন।
2. `Ctrl + F` চাপুন এবং `01733054857` সার্চ করুন।
3. তিনটি জায়গায় নতুন bKash নম্বর বসান।
4. ফাইল Save করুন এবং ব্রাউজারে খুলে Payment section ও FAQ পরীক্ষা করুন।

## নিরাপত্তা ও প্রকাশের আগে যাচাই

- নম্বরটি সঠিক কি না bKash-এ টাকা পাঠানোর আগে যাচাই করুন।
- ওয়েবসাইটে পরিবর্তন দেখাতে হলে সম্পাদিত HTML ফাইলটি GitHub repository-র সঠিক branch-এ commit/push করতে হবে।
- এই README তৈরি করার সময় HTML preview ফাইলের `main` branch-এ আপলোড হওয়া নিশ্চিত করা হয়নি।
